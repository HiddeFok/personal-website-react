# Personal Website in Astro

My personal website: depicting coding projects and research. Built with
[Astro](https://astro.build), static output and zero shipped JavaScript.

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
```

## Build

```bash
npm run build    # static site → dist/
npm run preview  # serve the build locally
```

## Deploy

Automatically deployed using GitHub Actions.
